# Kite v1.1.0: visual check

**What this is:** each screen and state of v1.1.0, captured with invented content and looked at beside the matching reference frame, with what differs and whether that is accepted.

**How it was made:** `apps/web/tests/visual/v110-shots.ts` drives a simulated call on the overlay rig in a browser with a temporary profile, 4 Nov 2026. It captures pages only, never the screen, so nothing else on the computer can appear. See-through states are captured over a busy test backdrop.

**Kite's captures** are in `docs/testing/v1.1.0-screenshots/`. **The side-by-sides and reference frames** hold another company's UI, so they stay in the git-ignored `docs/design/references/` folder and are never committed. The frames are listed in `docs/design/reference-catalog.md`.

**Not compared:** `browser-split-1.png` and `browser-split-2.png` were not found on this computer. The developer chose to go ahead without them (4 Nov 2026), so the browser view was compared with the older `browser-split.png`, and the blurred background of `browser-connect.png`.

## Found by this check, and fixed before release

| What was wrong | Fix |
|---|---|
| The selected Theme button was a blank white circle: its icon took the wrong colour | Its colours are set per state |
| "View in dashboard" wrapped to two lines at 400 px | It stays on one line |
| The expand and collapse icons read as a plus sign | Diagonal arrows, as the brief's ⤢ |
| The ghost layouts overlapped on a small screen | Never wider than a third of the screen |
| A cut-off chip at the start of bar 2 | At most four chips, which fit |
| ▾ next to the microphone was almost invisible | Normal text colour |
| "Keep going" ran off the end of bar 1 while End asked to confirm | It says "Cancel", and the simulated calls check it stays on screen at both widths |
| Noise joined the question next to it, so it never collapsed | Noise and speech never share a line or a bubble, and noise stays out of the question and the chips |
