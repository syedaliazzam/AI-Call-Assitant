# Release 1.3.0: regression checklist (before "go live")

**What this is:** the one human pass before the accountSync switch goes to everyone and the 1.3.0 draft is published. It covers account sync (ADR-0049 to ADR-0052), Connect (ADR-0053), the two themes (ADR-0054) and the desktop flow that now matches the reference app (ADR-0055). Automated checks (unit, harness, the real-shell click-through and protection tests, the production launcher and link checks) are not repeated here.

**Setup:** your account and the test account have the switch (`KITE_SYNC_USERS`); everyone else does not. Install the **1.3.0 draft** from `Zainpak123/kite-releases` (it is unpublished, so no one else gets it). Use invented session details only. Mark each step ✅ or ❌ and, for ❌, write what you saw.

**Cost:** steps 6.6 and 6.7 ask for two answers on the fast model (well under $0.01).
