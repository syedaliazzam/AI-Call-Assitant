# Release 1.3.0: test checklist (after go live)

**What this is:** the developer's pass over 1.3.0 once it is live for everyone: account sync, the one dashboard, the desktop cards, the compact view with its six positions, Private, the reference typography and the small UI changes. Automated checks (unit, harness, the real-shell smoke, click-through and protection tests, the production launcher, link, sync and paid desktop checks) are not repeated here.

**Setup:** install 1.3.0 from the update (or `Paramount-AI-Setup-1.3.0.exe` from the Latest release). Use invented session details only. Mark each step ✅ or ❌ and, for ❌, write what you saw.

**Cost:** section 11 asks for about five answers on the fast model (well under $0.05).

## 1. Install, update and the logo

| # | Do | Expect |
|---|---|---|
| 1.1 | With 1.2.0 installed, open it and wait (or restart it). | It offers the update; after the restart **About** says 1.3.0. You are still signed in; your Private setting and overlay place are kept. |
| 1.2 | Look at the taskbar, the Start menu, the window frame and a browser tab on call.paramountintelligence.co. | The company "P" mark everywhere, with "Paramount AI" beside it in the frame, the web header, the sidebar and sign-in. No parrot anywhere. |

## 4. The compact view

| 4.5 | Bars over Notepad: click in the empty space beside bar 2 and between the panels, and type. Then the same over a Google Meet tab's chat box. | The click and the typing go to Notepad / Meet. The bars' own buttons still work. |
| 4.6 | **Ctrl+Alt+Left / Right** several times; **Ctrl+Alt+Down**, then **Ctrl+Alt+Up**. | The bars jump one place along the row (left, centre, right), stopping at the ends; Down goes to the bottom row in the same column, Up back. Each place is about 16 px from the screen's edges, never under the taskbar. |
| 4.7 | On the bottom row, open the answer panel, the transcript and ⋮. | Everything is mirrored: bar 1 at the bottom, panels and menus above it. |
| 4.8 | **Ctrl+Alt+Shift+Arrows**; then Ctrl+Shift+Arrows in Notepad. | A small nudge (about 20 px); in Notepad Ctrl+Shift+Arrows still selects words (Paramount AI never takes them). |

| 4.10 | **⋮ → Position**. | A 2 × 3 grid with the current place highlighted; a click moves the bars there. |
| 4.11 | With two monitors: drag the bars to the second one, end the call, start another. | Each monitor remembers its own place; the new call opens where you left it on that monitor. |
| 4.12 | Compact (the icon). | A small dark square with moving level bars; drag moves it, a click restores. |
