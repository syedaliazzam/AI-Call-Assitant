# Kite v1.1.0: Step 0 plan

**Status:** approved by the developer ("go", 4 Nov 2026) with all four recommendations in section 2 and the section 3 and item-level choices accepted. Branch `v1.1.0`, from `main` at `a088534`.
**Companion:** `docs/design/reference-catalog.md`.

**Added at approval: acceptable use.** A one-time first-run notice and a user-guide section, in the developer's exact words:

> Use Kite in calls where AI assistance is allowed — your own meetings, client calls, practice and mock interviews. Don't use it to get hidden help in interviews, exams or assessments where outside help isn't permitted. Screen-share protection only hides Kite's windows; it does nothing against monitoring or proctoring tools. Recording or transcribing others may require their consent.

It shows once per device on whichever window opens first (home panel, dashboard), including for people upgrading, and never in the overlay during a call. **Files:** new `src/features/notices/AcceptableUseNotice.tsx`, `src/core/storage/hintPrefs.ts`, `app/(app)/layout.tsx`, `app/(panel)/layout.tsx`, `docs/user-guide/using-kite.md`. **Test:** unit (once only, storage blocked), harness, visual check.

## 2. Decisions for you

Saying "go" accepts every recommendation. To change one, say so with its number.

### Needs a real choice

1. **Accurate transcription "Auto" and the 661 MB download (item 18).** Auto as the default would otherwise start a 661 MB download for every user unasked. **Recommended:** Auto uses the engine only once it is downloaded, and the download takes one click, offered once on the home panel and in Settings. Never silent.
2. **Gates for `missing-info` and `cv-embellishment` (item 29).** Both already failed at v1.0.0 and shipped anyway (7.75 against ≥ 8; 6 invented items against zero). With your one-fix-then-stop rule, the absolute gates will very likely stop the release on an old weakness. **Recommended:** gate them against their baselines for this release: `missing-info` ≥ 7.60; `cv-embellishment` score ≥ 7.10 and at most 6 invented items, with one prompt round (better examples, not more bans) if either misses. Report the absolute targets as still unmet.
3. **Update test order (items 32 and 34).** Item 32 tests auto-update "on the releases feed" before item 34 publishes, and publishing reaches every teammate's auto-updater. **Recommended, two steps:** before publishing, run a kept copy of the real 1.0.4 against a local feed serving the real 1.1.0 files (edit only that copy's `resources/app-update.yml`, temporary profile). After publishing, repeat once against the real feed.
4. **What "≤ 12 words" means as a gate (item 16).** The rule already says 12 twice and the model still overshoots, so a 100% gate would fail on chance alone. **Recommended:** at least 95% of raw answer lines are ≤ 12 words in the paid runs, and the card enforces the rest: a longer first line breaks at a clause boundary and the remainder becomes the first bullet. No extra request.

### Defaults I will use unless you object

5. **Punctuation runtime (item 19).** The speech WebAssembly build has no punctuation functions (checked in the `.wasm`), so the model cannot run through it. Use `onnxruntime-web` in the speech worker, one path for browser and desktop. If its runtime proves too heavy (over about 15 MB) or slow (p95 over 100 ms per line), fall back to desktop-only through the native engine already shipped, and tell you.
6. **Theme scope (items 2, 9).** One setting, default System, covering the home panel, overlay, panels and call window. Dashboard, wizard and other working pages stay light: dark for all of them is its own audit.
7. **The transcript panel replaces bar 2 (item 5).** As in the newest frame: its header carries bar 2's controls. Your "under the bars" still holds, because it sits under bar 1.
8. **Panels are the bars' width, in one window (item 8).** The reference's narrower transcript and wider answer panel would add click-catching transparent areas. Recorded as an accepted difference in the visual check.
9. **Chips stay in bar 2 (items 4, 20).** Your item 20 names chips, though the newest frame shows plain words. While a question is being asked, bar 2 shows it highlighted, replacing v1.0.4's separate "Them:" row.
10. **Merging follows your wording literally (item 15):** within 60 s and in the same call. v1.0.4's "same words at any time" goes, so a question repeated ten minutes later gets its own entry.
11. **Things you did not list, kept rather than removed:** the script bar stays on Ctrl+Alt+S, off the menu. Answer preferences stay at the end of the live ⋮ (test 1b.9 and the parity doc rely on them). Fade moves to Settings → Overlay.
12. **"Start calls in the overlay" is retired on shells ≥ 1.1.0,** because item 12 makes the overlay the only call start. Older shells keep the setting.
13. **Clear never empties the card (item 6).** It stops a stream and returns to the newest answer, because item 15 forbids an empty state when answers exist. This differs from the reference.
14. **Private stays off by default,** as now and as in the reference.
15. **Reversing ADR-0030's newest-first order everywhere live** (overlay, call window, browser), per item 5. Review also defaults to oldest first.

## 3. Design points that shape everything

**Windows after this release**

| Window | Route | Created | Notes |
|---|---|---|---|
| Home panel | `/home` | At start | New. Frameless, about 400 × 560, resizable. Hidden during a call |
| Main | `/`, `/sessions/*`, `/live/*`, … | When first needed | Today's window, and **still hosts the call** (audio, speech, answers). Shows Connect, then minimises |
| Overlay | `/compact/[id]` | During a call | Bars and panels in one transparent window that grows and shrinks to fit |
| Side pages | `/`, `/sessions/[id]/edit` | Only if asked during a call | New. **Dashboard ↗ and Edit session must not navigate the main window, because that would end the call.** A second `/live` page refuses to start while a call runs |
| Snap zones | `/overlay-zones` | While dragging | New. Transparent, click-through, never focused |

Every window gets `protection.attach()`. All load only the Kite origin and use the same secure web preferences. All remain in the taskbar and Alt+Tab (CLAUDE.md), except the snap zones, which are a momentary drawing aid and are not a place Kite could be hidden.

**Rollback safety:** if the web app is rolled back, a 1.1.0 shell would get a 404 on `/home`. The shell detects that and opens the main window at `/`, as 1.0.4 does. Tested.

**Older shells against the new web app**

| Feature | Shell ≥ 1.1.0 | Shell 1.0.4 and older (feature-detected) |
|---|---|---|
| Home panel | Yes | Not used: opens the dashboard as today |
| Bars and panels | Window fits them | Fixed window; panels share its height and menus scroll |
| Top-left, per-display, snap zones | Yes | Hidden: their old presets only (an old shell rejects `top-left`) |
| Chat shortcut | Global during a call | Works while Kite has focus |
| Private | Every window | Overlay only, and the menus and Settings say so |
| Screenshot leaves out Kite's windows | Yes | As today |
| Zoom, battery detection | No bridge needed (CSS `zoom`, `navigator.getBattery`) | Same |

**New optional bridge calls:** `openPagesWindow(path)` (known route prefixes only), `windowControl('minimize' | 'close')`, `setOverlayLayout({ transcript, answer, popupHeight })`. `ShareProtectionState` gains `scope`. Each on its own IPC channel, Kite main frames only, every value checked.

**Database version 8 (item 31 tests it).** Sessions gain `contactName` and `lastCallMs`. Answers gain `callStartedAt`. The upgrade fills the new fields on old rows; export and import learn them, and older export files still import. No other row changes. Dexie lets a rolled-back build open a newer database (checked at v1.0.0).

**Hotkeys after this release** (Settings → Hotkeys follows)

| Action | Keys | Scope |
|---|---|---|
| Answer; Screenshot | Ctrl+Enter; Ctrl+Shift+Enter | Global during a call |
| Chat | **Ctrl+Shift+Space** (moved) | **Global during a call** (it takes focus so you can type) |
| Clear transcript | **Ctrl+Shift+Backspace** (new meaning) | Kite focused |
| Clear answer; Previous, next | Ctrl+Backspace; Ctrl+Left, Ctrl+Right | Kite focused (global would break typing in other apps) |
| Show or hide; Move | Ctrl+Alt+H; Ctrl+Alt+Arrows | Global during a call |
| Ask Kite; Script bar | Ctrl+Alt+K; Ctrl+Alt+S | As today |
